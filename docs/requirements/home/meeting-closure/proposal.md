# 会议闭环与会后纪要

适用产品为 CMO，归属首页、日程与待办。[本项进度与任务](../../../../../onosan_workbench/docs/requirements/README.md#首页日程与待办)

## 业务目标

同一场会议在日程中聚合成一条，用户会后能从该记录查看可用纪要。

## 验收条件

- 用一场双来源会议核对聚合显示及原始记录回查，再验证会后内容入口。

## 交付进展

双来源合并已接入，完整闭环余项见计划

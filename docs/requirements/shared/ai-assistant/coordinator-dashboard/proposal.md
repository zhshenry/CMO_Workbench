# 总管操作右侧看板

适用产品为 CMO，归属跨工作台能力。[本项进度与任务](../../../../../../onosan_workbench/docs/requirements/README.md#bot-与-ai-工作区)

## 业务目标

总管和用户可以交替操作同一张看板卡片，共享已保存的布局和卡片状态。总管可按需查询卡片内容，使用与看板相同的数据源和统计口径。

## 验收条件

- 用户移动并保存卡片，总管改同一张卡的样式，用户调尺寸后总管能读回新值。
- 总台对话可查询已保存卡片的日程待办统计和 New API 今日 Token 消耗，统计与卡片一致，并显示缓存或未连接的来源状态。

## 交付进展

看板本地人机接续与内容读取 · 3/3 项

# Bot 对话操作卡片

适用产品为 CMO，归属跨工作台能力。[本项进度与任务](../../../../../../onosan_workbench/docs/requirements/README.md#bot-与-ai-工作区)

## 业务目标

在主对话以同一种卡片呈现执行结果和操作请求，以业务对象、状态及下一步为主要内容。

## 验收条件

- 在并排和悬浮对话分别验证成功结果与待确认请求，卡片能显示状态并承接对应操作。

## 交付进展

固定和悬浮卡片专项 · 2/2 项

# 办公材料与 Bot 工作台

适用产品为 CMO，归属跨工作台能力。[本项进度与任务](../../../../../../onosan_workbench/docs/requirements/README.md#bot-与-ai-工作区)

## 业务目标

办公助理与工作台共用办公事项及出处，用户可从已有事项发问、回看来源或转成待办。

## 验收条件

- 选中办公事项发起对话，定位到同一出处，确认生成待办后能按真实事项读回日期。

## 交付进展

材料读取和出处已接入，办公同源续做待补

# 站点授权

适用产品为 CMO，归属网页工作台。[本项进度与任务](../../../../../onosan_workbench/docs/requirements/README.md#网页工作台)

## 业务目标

用户能在助手需要网页权限时辨认站点、决定授权并继续处理。

## 验收条件

- 分别验证同意和拒绝，检查后续动作遵循本次授权结果。

# CMO Bot 长期记忆任务

## 任务清单

每项按验收条件验证后更新状态，同时记录测试入口或版本。此次本地验证使用临时数据库和模拟模型，记忆、输入路由、消息队列和 Host 共 56 项回归通过。回归入口包括 [记忆存储测试](../../../../../tests/bot-memory.test.ts)和 [Bot 运行时测试](../../../../../tests/bot-message-runtime.test.ts)。

| 任务 | 状态 | 验收条件 |

| 自动记忆开关 | 已完成 · 本地 | 设置只有一个默认关闭的开关。关闭作废在途结果，再开只审查之后的新发言。用户可在 Bot 对话中主动保存。 |

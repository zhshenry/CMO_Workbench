# Bot 对话与右侧工作台布局

适用产品为 CMO，归属跨工作台能力。[本项进度与任务](../../../../../../onosan_workbench/docs/requirements/README.md#bot-与-ai-工作区)

## 业务目标

用户可边聊边操作对应工作台，并按窗口空间使用并排或悬浮对话。

## 验收条件

- 并排和悬浮两种入口都能进入同一 Bot 的主对话，切换时仍能继续处理当前对象。

## 交付进展

并排、悬浮核心流程 · 2/2 项
